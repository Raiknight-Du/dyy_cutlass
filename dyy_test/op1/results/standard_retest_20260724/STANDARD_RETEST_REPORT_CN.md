# OP1 Pure Matmul 标准性能重测报告

日期：2026-07-24

## 结论

已按照 `dyy_test/PERFORMANCE_TEST_STANDARD_CN.md` 重新完成 M_72a pure matmul
配置搜索和最终性能验证。最终稳定源码为：

```text
dyy_test/op1/op1_best.cu
```

13-shape 最优配置平均时延之和为：

```text
20.318088784 ms
```

该值是各 shape 独立运行的 mean 之和，不是一次连续执行13个 shape 的端到端时间。

## 标准测试条件

- CUDA Event；
- 1 次 warmup；
- 每个样本连续执行 10 次，记录 `elapsed / 10`；
- 持久化随机 A/B/SFA/SFB 输入；
- 每次执行前确认 GPU 无其他 compute process；
- shape 和候选顺序按轮次旋转、反转；
- 最终稳定二进制每个 shape 独立测试 25 轮。

随机数据目录：

```text
dyy_test/m72a_voidc_matmul_20260719/random_datasets
```

## 搜索过程

1. 每个 shape 的旧 Top-20 共260个 shape-config 组合先完成批量五轮筛选。
2. 为消除同进程持续负载状态影响，260个组合全部以独立进程重新测试五轮，
   共1300个标准样本。
3. 对均值差小于单轮波动的候选追加20轮，与原五轮合并为25轮，
   共500个追加样本。
4. 根据25轮均值确定接近候选，更新并重新编译 `op1_best.cu`。
5. 最终稳定二进制完成13 shape x 25轮，共325个标准样本。

## 统计接近的配置

以下 shape 的候选置信区间仍有重叠，不能宣称硬件上存在稳定的显著差异；稳定源码按
25轮样本均值选择：

- Shape 2：E64x64 C2x1x1 与 E128x64 C2x1x1；
- Shape 5：Eauto C2x2x1 与 Eauto C4x1x1；
- Shape 6：E128x16 C4x1x1 与 E128x16 C2x2x1；
- Shape 10：Eauto C1x2x1 与 E128x128 C1x2x1；
- Shape 12：M128N192 E128x64 与 M128N256 E128x128；
- Shape 13：E128x128 与 Eauto。

Shape 1、3、7、8、9 的领先关系更清楚。Shape 4 的 E64x64 均值领先，但差距相对
动态频率波动仍较小。
